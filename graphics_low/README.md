# 降低游戏画质

进入游戏后把「设置 → 画面」里的帧率、渲染精度、抗锯齿调到低档，并在第一次执行时把原始档位记下来，供「恢复游戏画质」读取。

## 运行前提

- **必须以管理员权限启动一条龙**。游戏进程是管理员权限，普通权限的程序点不动游戏里的任何按钮，会表现成「点了没反应」。
- 游戏语言是简体中文。界面识别按中文文字匹配。

## 一条龙里的位置

排序值是 50，写在 `graphics_low_factory.py` 里（插件仓库要求 `*_const.py` 必须和 `plugin.json` 逐字节一致，排序值放不进 const）。排在最前面，让后面的应用都在低画质下跑。

本插件覆盖了 `create_run_record()` 返回 `None`，也就是没有「今天已完成」的记录，一条龙每次运行都会执行它。

装好后它默认是**未启用**状态，需要到一条龙的运行列表里手动勾上。

## 设置项

在一条龙的运行列表里点本应用右侧的设置按钮，会从右侧滑入一页独立设置界面，三项各一个下拉框，改完即时存进 YAML。

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 目标帧率 | 30 | 30 / 60 / 无限制 |
| 目标渲染精度 | 0.8 | 0.8 / 1.0 / 1.2 |
| 目标抗锯齿 | 关闭 | 关闭 / TAA / SMAA |

选项文字必须和游戏里下拉框的文字一模一样，否则应用会直接报「目标值不在可选项里」。

## 原始档位记录

第一次跑成功时写进 `config/graphics_low_snapshot.yml`（**不在实例目录下**）：

```yaml
original_fps: '60'
original_render_scale: '1.0'
original_antialias: SMAA
snapshot_date: '2026-11-02'
```

只在 `original_fps` 为空时写一次，避免第二次跑把低画质当成原始档位覆盖掉。

**为什么全局一份**：游戏客户端只有一套全局画质设置。如果按实例各存一份，一条龙顺序跑多个账号时，第二个账号看到自己那份快照是空的，就会把已经调低的档位当成「原始档位」记下来，之后恢复画质恢复的是低画质。

设置页底部有一张「原始档位记录」卡片，显示当前存了什么；点「清空记录」就会把上面四项清空，下次运行重新记录。这一项对所有账号同时生效。

自己的三个目标档位照旧按实例存，在 `config/<区服>/one_dragon/graphics_low.yml`。

## 执行链路

传送「录像店 / 房间」 → 回到大世界 → 点左上角「菜单」开暂停菜单 → 点底部「设置」 → 确认停在「画面」页签 → 记录原始档位 → 改帧率 → 改渲染精度 → 改抗锯齿 → 连点两次返回回到大世界。

游戏里改画质是即时生效的，没有保存按钮，所以链路里没有确认节点。

## 坐标说明

`graphics_low_screen.py` 里的坐标全是 1080p 下实测的。框架截图时会把任意 16:9 画面拉伸到 1920x1080 再识别，点击时按实际窗口尺寸换算回去，所以 2K / 4K 不用另外适配。16:10 和 21:9 会被非等比拉伸，属于框架既有前提。
